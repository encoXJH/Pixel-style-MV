# 像素叙事风格规范与验收标准

默认配置来自 `assets/style.json`，`schema_version=3`，风格档案为 `ailo-public-pixel-narrative-v2`。本规范描述当前 Skill 实际实现的叙事、镜头、美术、动作、转场、字幕、信息密度和声音链路，用于生成与复核原创程序化像素叙事 MV。

参考证据包括 29 件公开作品的画面抽帧，以及用户指定的 Ailo《出现又离开》380 秒参考视频的全片与关键动态窗口分析。分析仅用于画面、动作和叙事，不复制原作者素材、工程、音轨混音或逐帧时间轴。因此，本规范保留已确认的风格要素，但不把结构校验或技术 QC 解释为原工程参数、原始混音或主观艺术效果已经 100% 一致。

## 1. 画布、像素与编码

| 项目 | 默认值与规则 |
| --- | --- |
| 工作画布 | 480×270；场景、角色、道具、天气、特效、运镜和转场在低画布完成。 |
| 放大 | 固定 4 倍最近邻到 1920×1080，保持硬边像素块，不做双线性平滑。 |
| 帧率 | 30fps，总帧数为 `ceil(歌曲时长 × 30)`。 |
| 视频编码 | H.264/libx264，CRF 14，preset medium，yuv420p。 |
| 音频编码 | AAC 256kbps、48kHz；用户歌曲始终是主音乐。 |
| 字幕 | 在最近邻放大后的 1920×1080 画布合成，避免可读文字被低分辨率像素化。 |
| 中间帧 | 逐帧流式送入 FFmpeg；只保存镜头关键帧，不默认落盘整段 PNG 序列。 |

像素画面使用硬边像素簇、有限共享色板、规则抖动/半调和明确的镜头尺度。禁止使用运动模糊、光流补帧、亚像素重采样或帧混合制造“流畅感”。新时间轴和画面使用 `art_version=3`，时间轴为 `schema_version=3`；旧渲染分支只用于兼容旧时间轴。

## 2. 参考风格档案与完整要素范围

`reference_profile` 明确记录以下创作约束，并由 `style-qc.json` 检查其是否进入时间轴：

- **叙事结构**：翻牌书场牌或物件片头、日常蒙太奇、离别、回忆插入、独立间奏蒙太奇、高潮、母题返回；全片只围绕一个主题推进。
- **镜头语言**：侧面人物构图或正面舞台构图，环境建立、双人/单人中景、情绪特写、物件插入交替出现。
- **构图装置**：全屏翻牌书场牌、海景车厢、双人长椅、分隔构图、冷暖双人肖像、晴雨/晴雪分屏、想象泡、拍立得照片框、胶片框、物件特写、正面舞台。
- **色彩**：白天克制的天空色与米白，晨夕珊瑚和琥珀，雨夜靛蓝与暖色实景灯，回忆仅做克制琥珀处理而非全屏深褐。
- **表演**：保持帧姿态、眨眼、中性/开心/悲伤表情、坐姿与一像素待机起伏；每个镜头一个清晰主动作，环境运动作为辅助，画心时手部跟随绘制轨迹。
- **特效**：雨雪、海面高光、星光、像素爱心、想象泡、回忆闪点、烟花、舞台灯光、胶片穿孔、规则抖动和克制暗角。
- **叙事引导**：通过手机、信件、车票、站牌、照片等剧情内道具传达信息，不添加点赞、关注等社交 CTA。
- **信息密度**：细节丰富的环境与简洁主动作并存，底部居中紧凑字幕框，不让装饰遮住人物表演。
- **声音**：仅实现原创低电平程序化 cue 与歌曲闪避；不声称得到参考作品的混音、音效或分轨。

## 3. 共享色板、角色与连续性

核心色为米白 `cream #F4EBDD`、墨色 `ink #25232A`、靛蓝 `indigo #20264A`、琥珀 `amber #F2B35D`、珊瑚 `coral #E9786B`、红色 `red #C94A4A`。扩展色板覆盖天空、海面、玻璃、雾气、金属、木材、石材、人物肤色和发色；完整色值以 `assets/style.json.palette` 为准。天空和海面可按固定色标插值，再经滤镜量化到共享色板，不引入随机素材风格。

角色配置固定在 `characters`：主角为墨色头发、蓝色外套、靛蓝裤和红色配饰；同伴为木棕头发、米白外套、红色下装和珊瑚配饰；橘猫为琥珀身体与米白配饰。镜头种子由全片种子和镜头序号确定，避免无原因换装、换色或改变母题。

| 镜头类型 | 低画布角色高度 | 构图用途 |
| --- | ---: | --- |
| `landscape` / `wide` | 50 像素 | 建立环境、人物关系与空间位置；`landscape` 默认不画人物。 |
| `medium` | 74 像素 | 对话、等待、行走、骑行、阅读和道具互动。 |
| `close` | 104 像素 | 单角色情绪与面部细节；双人相拥限制为 82 像素并贴近站位。 |
| `object` | 通常不画完整人物 | 桌面或物件特写，最多两件道具；玻璃画心改画手部特写。 |

角色采用阶梯轮廓、刘海与侧发、五官、腮红、领口袖口和鞋底细节。双人交谈、长椅坐姿与相拥使用明确站位和环绕肩背/腰部的手臂；`dual_portrait` 使用独立冷暖背景下的双人正面肖像与中性/开心/悲伤表情，不与普通场景特写混用。

## 4. 连续叙事、章节与镜头结构

先根据整首歌词确定唯一 `story_theme`，以八段章节场景弧线保证连续性，再由明确地点、行动和情绪意象纠正当前句场景；“你”“梦”“夜”等虚词或通用词不能单独触发跳场。歌词、句间 `instrumental` 和片尾 `epilogue` 分别建立叙事基础段，长段拆分时改变场景、景别、动作、构图或天气，不得复制同一画面。RMS 用于识别高潮并设置 `energy_peak`，不会仅因高潮就强制换用紫色舞台滤镜。

除片头 `prologue` 和片尾 `epilogue` 外，正片阶段为：

| 阶段 | 进度区间 | 阶段内镜头序列 |
| --- | --- | --- |
| `encounter` | 0–18% | `wide → medium → object → wide → close → medium` |
| `development` | 18–42% | `wide → medium → close → wide → object → medium` |
| `separation` | 42–66% | `wide → close → medium → object → wide → close` |
| `memory` | 66–84% | `object → close → wide → medium → object → close` |
| `return` | 84–100% | `wide → medium → wide → close → medium → wide` |

片头以全屏 `title_board` 翻牌书场牌开场，片尾回到同主题场景与主天气并再次以书场牌收束；车站后续建立镜头与返回阶段可使用 `day/rain`、`day/snow` 左右分屏。分屏中央保留深色分隔线，左右天气粒子分别裁切，并强制静态镜头避免分隔线被运镜移动。书场牌目的地与线路随主题变化，不再固定为海边站。

每个镜头保存 `kind`、`story_phase`、`chapter`、`narrative_beat`、`action`、`expression`、`variant`、`camera`、`blocking`、`effects`、`sfx`、`density`、`energy` 和 `energy_peak`。`blocking` 记录 `environment_only/object_table/center_single/two_shot/bench_pair/separate_sides/close_pair/dual_portrait` 等布局、主动作和银幕方向，保证这些创作决策不只是文档描述。

每句歌词先由 `_build_lyric_cues()` 建立唯一 `lyric_cue`，目标起止时间只通过 `ceil(target_seconds × fps)` 量化一次。句界镜头直接继承 cue 的起始帧，固定 `beat_snap_ms=0.0`、`beat_snap_applied=false`；字幕也从同一 cue 复制帧区间，不再单独量化。`timing.beat_snap_window_ms` 仅为保留配置字段，不参与当前句界镜头或字幕定位。

同一歌词因最长 8 秒限制拆成多个镜头时，各分块继承相同的 `line_id` 与 `lyric_cue_id`，cue 的 `shot_ids` 记录全部视觉分块。镜头、字幕和逐帧日志均使用左闭右开区间 `[start_frame, end_frame)`。相邻歌词起点落在同一帧、单句不足一个有效视频帧或起止时间无效时明确拒绝，避免生成无法区分的绑定。

句间空白和最后一句之后的时间不再依附上一句 cue；这些区间使用独立 `instrumental/epilogue` 镜头，`line_id/lyric_cue_id` 均为空，逐帧 `visual_line_id` 只在真实活动 cue 内存在。`style-qc.json` 的 `montage_line_binding` 与 `epilogue_diversity` 分别检查该绑定和尾奏构图多样性。

| --- | --- | --- | --- |

| `bedroom` | 房间、床、窗、家、失眠、梦 | 照片、手机、猫、吉他 | `default` |
| `rain_street` | 雨、伞、街、夜、离开、孤独 | 红伞、信件、手机 | `rain_night` |
| `seaside` | 海、夏天、风、日落、沙滩、烟花 | 照片、信件、猫 | `dawn` |
| `station` | 车站、站台、列车、远方、出发、等待 | 车票、行李、信件 | `memory` |
| `train_interior` | 车厢、车窗、上车与旅途；绿墙、红椅、海景窗、竖杆和吊环 | 车票、行李、照片 | `default` |
| `stage` | 唱、歌、舞台、音乐、掌声、星光 | 吉他、麦克风、播放器 | `stage` |

`highway` 不是简化 fallback：画面包含海岸与山体远景、城市灯光、汽车旅馆、`SUNSET` 路牌、棕榈、透视公路、车道线、双侧护栏、电线杆与下垂电线；车辆按本地帧行驶，雨天/夜晚使用冷色湿润路面与反光，晚霞使用金色太阳和珊瑚地平线。

道具库包括红伞、信件、照片、吉他、橘猫、手机、车票、行李、播放器、卷轴、单车、书、相机和麦克风。普通镜头只选当前歌词明确匹配的最多两件道具；物件镜头没有明确匹配时才回退到全片母题，玻璃画心镜头清空普通桌面道具。车站相拥中的橘猫与红伞属于固定叙事构图，不计入桌面道具数量。

手机、信件、照片、车票、站牌等只承担剧情内信息引导。当前 Skill 不生成关注、点赞、评论或购买链接等界面式交互引导。

## 6. 人物动作与环境动态

动作词表为 `title_board`、`waiting`、`walking`、`cycling`、`reading`、`talking`、`playing`、`photographing`、`embrace`、`heart_glass`、`train`。相拥强制使用中景以保留双人，玻璃画心强制使用物件特写，骑行、阅读和拍照强制使用中景，避免动作被错误构图裁掉。等待和交谈在车站/车厢可使用双人或单人坐姿，`expression` 为 `neutral/happy/sad`，并进入普通角色与双人肖像。

- **保持帧表演**：默认每 3 个输出帧切换姿态，眨眼保持 2 帧；等待、交谈、阅读和弹奏加入一像素待机起伏，不使用连续骨骼平滑。
- **行走与骑行**：在低画布使用整数像素位移；骑行绘制完整单车并只保留一名骑手。
- **阅读、弹奏与拍照**：人物手持打开的书、吉他或相机，手臂姿态随主动作变化。
- **相拥与画心**：相拥保留双人侧面与环绕手臂；玻璃画心保留雾气、手部与心形轨迹，96 段轮廓逐步形成，手臂、手腕和指尖跟随当前绘制点。
- **列车与环境**：列车按镜头本地帧移动；海浪高光、飞鸟、星光、室内微粒、雨雪和灯光独立循环，静态背景缓存不得把长镜头变成冻结画面。
- **天气配色与层次**：`day/cloudy/rain/snow/sunset/night` 分别具有独立天空、云层、海面或窗外配色；多云加入整数像素云层漂移，晚霞保留地平线暖色带与粉/珊瑚云带，站台和室内窗外也响应天气变化。
- **天气粒子**：雨街基础雨滴为 36，天气绘制上限为 64；雪花上限为 52，舞台/滤镜粒子基础数量为 24。雨滴包含落地溅点，雪花包含横向漂移与少量十字像素细节。背景视差幅度为 2 像素。
- **天气自然切换**：歌词中的晴天、多云、雨雪、夜晚和晚霞关键词与叙事进度共同决定目标天气；日落、黄昏、晚霞、夕阳和金黄优先于通用“阳光”词，避免“黄昏阳光”被误判为白天。当前镜头不是分屏且其主天气与前一镜头主天气不同时，默认在镜头开头用 15 帧、5 阶段过渡；旧天气粒子逐阶段减少，新天气粒子逐阶段增加。画面通过 4×4 Bayer 阈值进行有序像素替换，过渡结束后必须与目标天气稳定帧一致，不做模糊、光流或帧混合。

## 7. 运镜规范

所有运镜在低分辨率画布执行，裁切、位移和缩放均为整数像素并使用最近邻，不使用运动模糊、光流或亚像素平滑。

| 参数 | 默认值 |
| --- | ---: |
| `camera.enabled` | `true` |
| `camera.max_crop_pixels` | 12 |
| `camera.pan_pixels` | 8 |
| `camera.motion_hold_frames` | 2 |

默认 `landscape/wide=pan_right`、`medium/object=push_in`、`close=static`。回忆阶段的环境和中景改为 `pull_out`，离别阶段特写改为 `push_in`，交替环境镜头使用 `pan_left`。支持 `static`、`push_in`、`pull_out`、`pan_left`、`pan_right`；分屏镜头始终 `static`。

## 8. 滤镜与调色

滤镜在低画布内完成叠色、分级暗角、规则矩阵扰动和共享色板量化。一般雨夜使用 `rain_night`，车站雨夜使用保留暖色砖面的 `station_rain`，日落和雪使用 `dawn`；左右分屏使用 `default`，避免单侧天气被全屏滤镜覆盖。其他镜头默认继承场景滤镜。

| 滤镜 | 叠色与强度 | 抖动 `dither` | 暗角 `vignette` | 用途 |
| --- | --- | --- | --- | --- |
| `default` | 无叠色 | 0.06 | 0.00 | 通用、卧室、古风、分屏 |
| `memory` | 琥珀色 0.08 | 0.08 | 0.06 | 校园、车站等回忆段落 |
| `rain_night` | 靛蓝 0.18 | 0.10 | 0.08 | 一般雨夜与离别 |
| `station_rain` | 珊瑚色 0.07 | 0.08 | 0.03 | 车站雨夜，保留暖色站台与肤色 |
| `dawn` | 珊瑚色 0.08 | 0.06 | 0.03 | 海边、公路晨夕与雪段 |
| `stage` | 紫色 0.12 | 0.10 | 0.08 | 舞台场景，不作为普通高潮强制滤镜 |

## 9. 叙事特效与信息密度

特效在天气之后、最外层边框之前合成：

| 特效 | 触发与视觉规则 |
| --- | --- |
| `title_card` | 旧时间轴和自定义镜头保留的米白小标题卡；当前片头片尾主要使用全屏 `title_board` 翻牌书场牌，含 ARRIVAL/DEPARTURE、时钟、标题、次要信息和滚动小字。 |
| `thought_bubble` | 梦、想象、如果、幻想等歌词触发，包含阶梯气泡与内部小叙事画面。 |
| `photo_frame` | 回忆阶段或照片/回忆等歌词的物件/特写镜头使用暖白照片边框。 |
| `film_frame` | 回忆阶段或对应歌词的其他镜头使用黑色胶片边与规则穿孔。 |
| `pixel_hearts` | 爱、心动、喜欢、相拥和画心触发硬边像素爱心上浮。 |
| `fireworks` | 烟花歌词或符合条件的高潮触发，多组 18 射线像素烟花。 |
| `stage_lights` | 舞台后半段使用三束克制透明感色光与顶部灯具。 |

密度配置为 `background_layers=5`、`max_object_props=2`、`max_emotional_overlays=2`、`max_weather_drops=64`、`max_snowflakes=52`。每镜头只保留一个主动作；细节应分布在背景层、天气和剧情道具中，不用大量同时闪烁的覆盖物淹没主体。

## 10. 字幕规范

- 字幕为底部水平居中的紧凑米白方框，不使用全宽字幕带。默认墨色粗描边 4 像素、方角，框内左侧为珊瑚色 `♪`，右侧为墨色中文黑体。
- 字号默认 42，最多 2 行，每行目标最多 26 字符，行距 8 像素；Windows 优先使用黑体 `simhei.ttf`，再回退到微软雅黑或 Noto Sans CJK。
- 框宽随文字收缩，最小 320、最大 1100 像素；水平内边距 20、垂直内边距 10、音符与文字间距 14 像素。
- 安全边距为 32 像素。配置底边距为 28，实际底边距取二者较大值，因此不会越过底部安全区。
- 默认最小对比度 4.5。自动换行、缩小字号并检查裁剪；无法完整显示时视为错误，不静默省略歌词。
- 字幕起止直接继承对应 `lyric_cue` 已计算的 `ceil(target × fps)` 帧边界，避免提前出现和二次量化错位；30fps 下一帧约 33.333ms。
- `band_height=180` 是时间轴兼容字段和 QC 底部检测区域高度，不代表可见全宽字幕带。

## 11. 转场规范

| 类型 | 默认时长 | 使用规则 |
| --- | ---: | --- |
| `hard_cut` | 0 帧 | 默认转场，全片以硬切为主。 |
| `white_flash` | 4 帧 | 高能量且段落变化的候选边界；每片最多 2 次。 |
| `scroll_wipe` | 12 帧 | 场景变化且接近段落位置的候选边界；每片最多 1 次。 |
| `match_cut` | 6 帧 | 同场景、不同镜头尺度的匹配裁切；每片最多 2 次。 |
| `memory_dissolve` | 10 帧 | 回忆段落的 4×4 Bayer 有序像素溶解；每片最多 2 次。 |
| `film_wipe` | 12 帧 | 章节变化时使用带胶片穿孔的纵向擦除；每片最多 1 次。 |
| `photo_reveal` | 12 帧 | 回忆段物件镜头以米白照片边框逐渐显现；每片最多 1 次。 |
| `iris_out` | 18 帧 | 仅用于全片结尾收光；按全片最后 18 帧计算，可跨越最后一个短镜头，不改变歌词区间。 |

转场帧区间均左闭右开，实际帧标记必须与 `timeline.json` 一致。`photo_reveal` 和 `memory_dissolve` 可替换候选位置上的白闪/卷轴擦除，保证回忆装置不会被通用规则完全抢占。自动 QC 只验证区间、类型/次数、标记、异常黑帧、冻结和帧差连续性，不证明主观自然度或原工程的精确转场帧数。

## 12. 歌曲、环境音与动作音效

`assets/style.json.sound` 是当前唯一声音设计配置来源：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `enabled` | `true` | 启用原创程序化声音 cue。 |
| `sample_rate` | 48000 | cue WAV 采样率。 |
| `cue_gain` | 0.11 | 基础 cue 电平。 |
| `max_cue_gain` | 0.22 | 单 cue 增益上限。 |
| `fade_seconds` | 0.08 | 短包络/环境声淡入淡出基准。 |
| `music_duck_db` | 3.0 | cue 活动时对歌曲做轻度侧链闪避。 |
| `mix_normalize` | `false` | 禁用 `amix` 自动整体归一化。 |

支持雨、风/雪、海浪、列车、脚步、单车铃、纸张/翻页、相机快门、烟花、房间 tone 和转场 cue。生成器输出 48kHz、立体声、16-bit PCM 的 `sound-cues.wav` 及 `sound-design.json`，再在封装时用 FFmpeg `sidechaincompress` 和 `amix=normalize=0` 与用户歌曲混合。cue 使用固定种子和峰值限制；禁用声音或空镜头时仍生成合法静音 WAV。

生成器没有参考音轨输入，故 `reference_audio_available=false`、`reference_mix_recreated=false`。本次参考分析只用于画面与叙事；这些 cue 是当前 Skill 的原创声音设计，不是参考作品原声、原始分轨或其混音参数的复原。

## 13. 制作步骤与效果校验

### 制作步骤

1. 保持歌词与歌曲为一一对应输入，正常入口不额外要求参考视频或提示词。
2. 生成对齐与音频特征，确定全片主题、章节场景弧线、歌词语义场景、RMS 高潮和镜头边界；歌词、间奏与尾奏分别规划。
3. 由 `plan_timeline()` 写入逐镜头叙事、动作、表情、构图变体、调度、运镜、特效、声音和密度字段，长间奏/尾奏生成独立蒙太奇。
4. 先执行 `validate_style_profile()`；结构校验失败则中止，不继续把缺少导演字段的结果包装为完整风格实现。
5. 在低画布绘制场景、角色、道具、局部动态与特效，执行整数运镜和共享色板滤镜，再合成高分辨率字幕。
6. 生成原创 cue WAV，与用户歌曲进行低电平闪避混音；完成 H.264/AAC 封装和三层技术 QC。
7. 查看 `generation.json`、`style-qc.json`、`sound-design.json`、`qc.json`、联系表、关键帧及最终视频；技术通过之后仍需人工艺术与试听复核。

### 结构校验标准

`style-qc.json` 逐项检查：参考档案存在、导演字段齐全、动作与特效词表合法、运镜为受支持的整数参数、物件和情绪叠加密度合规、转场均有配置、三个及以上尾奏镜头具有构图多样性、间奏/尾奏不残留旧歌词 `line_id`、片头片尾场景与主天气回环，并汇总镜头、动作、特效、运镜、转场和声音 cue 覆盖清单。

其 `scope=structural_style_implementation_only`、`art_review_required=true`，且不验证主观相似度、原工程参数、参考混音和精确原始转场时序。

### 独立预览与人工验收

`scripts/preview.py` 使用内置虚构样例或指定虚构歌词生成五类证据：

- `contact-sheet.jpg`：至多 12 张代表帧，均衡抽取书场牌、车厢、关键动作、构图与场景，检查主题连续、歌词语义场景、角色服装、镜头尺度、分屏、字幕安全区与信息密度，避免同类肖像占满预览。
- `motion-contact-sheet.jpg` 与 `motion/<shot_id>/`：每个代表动作 6 个本地帧，检查翻牌、行走、骑行、阅读、弹奏、相拥、轨迹画心、列车、爱心、烟花和整数运镜是否可读且连续。
- `transition-contact-sheet.jpg` 与 `transitions/<shot_id>/`：每个实际转场的过程帧，检查擦除方向、照片显现、胶片穿孔、有序溶解、匹配裁切和结尾收光。
- `weather-contact-sheet.jpg` 与 `weather/<weather>/`：六种天气各 3 帧，检查配色、云层、海面/窗外、雨雪粒子和环境动态。
- `weather-transition-contact-sheet.jpg` 与 `weather/transitions/<from>_to_<to>/`：五组天气变化过程帧，检查新旧天气占比、粒子密度和有序像素过渡是否连续。

预览使用等分估计时间轴，不读取音频、不生成 MV、不验证同步或完整技术 QC。必须实际查看图片和最终视频，不能用 `passed=true` 代替人工艺术验收。
